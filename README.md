# Контекстно-зависимый классификатор услуг по текстам объявлений на основе трансформерной модели BERT

Научная статья по теме выпускной квалификационной работы.
- **Студент:** А. Р. Тихомирова
- **Научный руководитель:** Э. Р. Тагиев
- **Кафедра:** Кафедра инженерной кибернетики, НИТУ «МИСиС»

## О чём работа
На онлайн-платформах объявлений продавец указывает одну микрокатегорию услуги,
но в описании может упоминать несколько — как самостоятельных, так и входящих
в состав комплексной работы. Из-за этого объявления не попадают в релевантные
микрокатегории, а пользователи не находят нужные услуги.

В работе предлагается контекстно-зависимый классификатор на основе RuBERT,
который по тексту объявления и выбранной микрокатегории предсказывает:
1. множество дополнительных микрокатегорий, упоминаемых в описании;
2. необходимость разделения объявления на несколько самостоятельных.

## Структура репозитория
- `article.tex` — исходный код статьи (LaTeX, XeLaTeX)
- `misisarticle.cls` — класс оформления НИТУ «МИСиС»
- `example/` — эталонная статья шаблона (не часть работы)
- `figures/` — иллюстрации к статье

## Сборка
Компилятор — XeLaTeX.

**Через GitHub Actions:** при каждом коммите PDF собирается автоматически. Результат — вкладка Actions → последний запуск → артефакт `article.pdf`.

**Локально через Makefile:**
```bash
make article
```

**Локально через консоль:**
```bash
# XeLaTex:
xelatex article.tex && xelatex article.tex
# Tectonic
tectonic article.tex
```

**В Overleaf:**
загружайте не весь репозиторий, а архив без примера:
```bash
make dist
# → dist/misis-article.zip
```
1. New Project → Upload Project → `dist/misis-article.zip`.
2. Menu → Compiler → **XeLaTeX**.
3. Главный файл — `article.tex`. Нажмите Recompile.
